# Al Jamiya Building Maintenance

A professional website for Al Jamiya Building Maintenance, a leading maintenance service provider in Dubai. This web application showcases services, handles customer inquiries, and includes a secure admin panel for managing customer messages.

## 🌟 Features

### Public Features
- **Interactive Home Page**
  - Service showcase with animations
  - Responsive image gallery
  - Smooth scrolling navigation
  - Service category highlights

- **Service Information**
  - Detailed service descriptions
  - Visual service presentations
  - Category-wise service organization
  - Easy navigation between services

- **Contact System**
  - User-friendly contact form
  - Service type selection
  - Location specification
  - Automated response confirmation

- **About Section**
  - Company information
  - Service highlights
  - Location details
  - Contact information

### Admin Features
- **Secure Admin Panel**
  - Protected admin login
  - Message management system
  - Secure session handling
  - User-friendly interface

- **Message Management**
  - View detailed messages
  - Delete messages
  - Sort by date
  - Quick action buttons

## 🛠 Technical Stack

### Frontend
- EJS templating engine
- Bootstrap 5 for responsive design
- Custom CSS animations
- JavaScript for interactivity
- Font Awesome icons

### Backend
- Node.js & Express.js
- MongoDB with Mongoose
- Express Session for auth
- EJS-Mate for layouts
- Method Override for REST

### Security
- Session-based authentication
- Environment variable protection
- Secure password handling
- Flash messages for feedback
